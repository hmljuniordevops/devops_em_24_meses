# 🚀 devops-journey

> Repositório principal do meu processo de transição para DevOps Engineer.
> 16 meses de estudo prático com trilhas paralelas, projetos semanais e um projeto mensal commitado.

---

## Sobre

Engenheiro de Service Desk com +10 anos de experiência em suporte técnico e gestão de chamados, em transição para **DevOps / SRE**.

Este repositório documenta toda a jornada: do primeiro comando Linux até uma stack completa com Kubernetes, Terraform, CI/CD e observabilidade rodando na AWS.

**Início:** maio 2025 &nbsp;|&nbsp; **Meta:** vaga Junior DevOps em agosto/setembro 2026

---

## Metodologia

Estudo diário de **2 horas divididas em 3 blocos de 40 minutos**, com 4 trilhas paralelas simultâneas para evitar monotonia:

| Trilha | Tecnologias |
|--------|-------------|
| 🐧 **Linux** | Terminal, Bash scripting, systemd, performance |
| 🐳 **Containers** | Docker, Compose, Kubernetes, Helm |
| 🌐 **Cloud & Redes** | AWS, Terraform, Ansible, Nginx, protocolos |
| 🐍 **Automação** | Python, Git, GitHub Actions, CI/CD |

Cada semana tem um **mini-projeto com commit**.
Cada mês tem um **projeto completo publicado** como repositório independente.

## Progresso semanal

Cada semana tem commits seguindo a convenção:

```
feat: descrição do que foi construído
ci:   mudança em pipeline ou workflow
infra: mudança em infraestrutura ou IaC
docs: atualização de documentação
fix:  correção de bug ou configuração
```
